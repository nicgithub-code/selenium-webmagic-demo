# 三、零基础学习路线（从"看不懂"到"能爬一个小站"）

> 这条路线按"先懂原理 → 再练静态 → 后攻动态 → 最后真实站点"的顺序，和本工程的 4 节课一一对应。
> 标了大致时间，仅供节奏参考，不必卡死。

---

## 阶段 0：环境到位（0.5 天）

- 装好 JDK 17、Maven，命令行能 `java -version` / `mvn -version`
- 装好 Edge 浏览器（你本机已有）
- 跑通本工程：`mvn -q compile exec:java` → 菜单选 `1`，看到 `output/lesson1-books.csv` 有 6 行
- **目标**：确认"工具链是通的"，把环境焦虑先消掉

## 阶段 1：理解"爬虫 = 发请求 + 解析 HTML"（1 天）

- 读 `docs/02-零前端基础速成.md`，会用 F12 看 Elements / Network
- 跑**第 1 课**，`BookListPageProcessor.java` 逐行读注释
- 重点理解三件事：
  1. 一个 URL 请求 → 拿回一段 HTML 文本
  2. 用 **CSS 选择器 / XPath** 从 HTML 里"剪"出想要的内容
  3. 用 `addTargetRequests` 把"下一页"链接喂回去，实现自动翻页
- **动手改**：把选择器里的 `div.book-card` 改成别的 class，看结果变化

## 阶段 2：认识"动态页面"与 Selenium（1~2 天）

- 跑**第 2 课**（建议 `-Dcrawler.headless=false` 看浏览器怎么干活）
- 理解：**数据不在 HTML 源码里、是 JS 跑出来时**，普通 HTTP 拿不到，必须让"真浏览器"渲染
- 记住 Selenium 的 4 个动作：`get` 打开、`WebDriverWait` 等待、`findElements` 定位、`click` 点击
- **动手改**：把 `waitSelector` 改成别的元素，体会"等错了就超时"

## 阶段 3：打通"下载器可插拔"的认知（半天）

- 跑**第 3 课**，对比 `lesson3-http.csv`（0 行）和 `lesson3-selenium.csv`（6 行）
- 结论刻进脑子：**解析逻辑和"页面怎么下载下来"解耦**。动态页难的是下载，不是解析。
- 读懂 `SeleniumDownloader.java`：它只是把"浏览器拿到的页面源码"交给 WebMagic 去解析

## 阶段 4：真实站点练习（1 天）

- 跑**第 4 课**（需联网），目标站 `quotes.toscrape.com` 是公认的新手练习站，无反爬、robots 允许
- 体会：解析代码和本地一模一样，只是 URL 换成了真实 https
- **下一步练习**：挑一个你喜欢的、robots 允许、无登录的静态站，照葫芦画瓢改选择器

## 进阶（想再往前走）

| 方向 | 该学什么 | 备注 |
|---|---|---|
| 更高效反爬应对 | 先找 JSON 接口，而不是直接上 Selenium | 见辨析第 5 条、文档 05 |
| 大规模抓取 | WebMagic 的 RedisScheduler、分布式、去重策略 | 别一上来就搞大，先稳 |

| 数据存储 | MySQL / Elasticsearch / CSV→Excel | 把 CSV Pipeline 换成数据库 Pipeline 即可 |

## 学习心法

1. **先跑通，再理解，最后改**。不要卡在"为什么"上不动手。
2. **选择器写不准，就用 F12 复制 + 自己改稳定版**，别死磕记忆。
3. **动态页优先找接口**，Selenium 是最后手段，不是首选。
4. **每次只改一个地方**，跑一下看结果——这是调试爬虫最稳的节奏。
