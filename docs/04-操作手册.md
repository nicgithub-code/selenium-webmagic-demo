# 四、操作手册（一步一步来 + 常见报错急救）

---

## 1. 环境自检（一次性）

打开命令行，确认两行都有版本号：

```bash
java -version    # 期望: 17.x
mvn -version     # 期望: 3.9.x
```

另外确认本机有 **Edge 浏览器**（Windows 默认自带，路径类似 `C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`）。

---

## 2. 最常见的 3 种运行方式

### 方式一（推荐新手）：一键脚本
双击工程根目录的 `run.bat`，或在根目录执行：
```bash
mvn -q compile exec:java
```
会进入菜单，输入 `1`/`2`/`3`/`4` 选课，`q` 退出。

### 方式二：直接指定某一课
```bash
mvn -q compile exec:java -Dexec.args=1   # 只跑第 1 课
mvn -q compile exec:java -Dexec.args=2   # 只跑第 2 课
# 0 = 一次性跑 1+2+3
```

### 方式三：打包成 jar 后运行
```bash
mvn -q clean package
java -jar target/crawler-demo.jar 1
```
说明：`package` 阶段会把所有依赖复制到 `target/lib/`，并写进 jar 的 `Class-Path`，所以 `java -jar` 能直接跑。

## 3. 各课要点 & 参数

| 课 | 是否需要联网 | 是否需要浏览器 | 常用参数 |
|---|---|---|---|
| 1 | 否（本地站点） | 否 | — |
| 2 | 否 | 是（会弹 Edge 窗口） | `-Dcrawler.headless=true` 改成无头 |
| 3 | 否 | 是 | `-Dcrawler.headless=true` |
| 4 | **是**（quotes.toscrape.com） | 否 | — |

> **无头模式**：`-Dcrawler.headless=true` 让浏览器在后台跑、不弹窗。服务器/批量跑必加；第一次学建议**不加**，看浏览器怎么动更直观。

## 4. 把示例改成"你自己的目标网站"

只需改 3 个地方（以第 4 课为例）：

1. **换起始 URL**：`Lesson4RealSite.java` 里的 `startUrl`
2. **改选择器**：`QuotePageProcessor.java` 里 `div.quote`、`span[@class='text']` 等，换成你目标站对应的 class
3. **改输出列**：`new CsvPipeline("output/xxx.csv", new String[]{"列1","列2"})` 的表头和 `row.put(...)` 的 key 对齐

> 不知道选择器怎么写？按 F12 → 右键目标内容 → "检查"，看它外层 class，再照 `docs/02` 写。

## 5. 常见报错 & 解决办法

### 5.1 `找不到 pages 目录` / `本地站点启动失败`
> 原因：程序必须在**工程根目录**运行（因为 `pages/` 相对当前目录找）。
> 解决：命令行先 `cd` 到 `selenium-webmagic-demo` 再跑；`run.bat` 已自动 `cd` 到自身所在目录。

### 5.2 `Unable to obtain driver` / `msedgedriver.azureedge.net ... DNS / 连不上`
> 原因：Selenium Manager 自动下载驱动时，访问微软 CDN 失败（公司网/墙常见）。
> 解决（本工程已替你做好第 1 步）：
> 1. 工程里已放好 `drivers/msedgedriver.exe`（匹配你当前 Edge 版本），**第 2、3 课开箱即用**。
> 2. 若你 Edge 升级了导致驱动不匹配，重新下载对应版本放到 `drivers/` 即可；
>    或手动指定：`java -Dcrawler.edge.driver=D:/path/msedgedriver.exe -jar target/crawler-demo.jar 2`
> 3. 下载地址：`https://msedgedriver.microsoft.com/<Edge完整版本号>/edgedriver_win64.zip`
>    （`<Edge完整版本号>` 在 Edge 菜单 → 设置 → 关于 Edge 里查看，例如 `139.0.3405.102`）

### 5.3 控制台出现 `Unable to find CDP implementation matching 139`（红色告警）
> **无害**。只是 Selenium 的 DevTools 调试协议不支持你这个 Edge 大版本，不影响正常抓取。
> 本工程只用到"打开网页/等待/点击/读取"，不依赖 DevTools，可以忽略。真要消除可升级 Selenium 到含对应 devtools 的版本。

### 5.4 CSV 用 Excel 打开中文乱码
> 本工程写的是带 **UTF-8 BOM** 的 CSV，Excel 能正确识别。若仍乱码，用 VS Code / Notepad++ 打开，
> 或确认文件是 UTF-8（不要另存为 GBK）。

### 5.5 `no main manifest attribute`（用 java -jar 但没打包）
> 解决：先 `mvn -q clean package` 再 `java -jar target/crawler-demo.jar`。

### 5.6 第 4 课报网络错误 / 0 条结果
> 原因：本机连不上 quotes.toscrape.com（无外网/被墙）。
> 解决：换网络后重试；或暂时跳过第 4 课，1~3 课完全本地可跑。

### 5.7 想用 Chrome 而不是 Edge
> 本工程针对 Edge 写好了。要换 Chrome：把 `SeleniumFactory` 里的 `EdgeDriver/EdgeOptions`
> 换成 `ChromeDriver/ChromeOptions`，并放一份 `chromedriver.exe` 到 `drivers/`（注意版本匹配）。
